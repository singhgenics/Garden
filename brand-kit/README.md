# Konso brand kit

Open `konso-brand-kit.html` (or the PDF). Folders: `logo/svg` (vector, use these first), `logo/png` (6000 px), `logo/foil` (real foil texture, for menus/cards/signage mock-ups), `fonts/` (Prata + Montserrat, OFL), `konso-tokens.css`, `brand-tokens.json`.

Colours: bottle green #051C0A, gold #D89D3C (foil gradient #EBB85B to #D19333), cream #F2E8D2.
Fonts: wordmark is artwork (never retype); Prata for headings; Montserrat for descriptor, labels, body.
Tagline: Pan Asian Kitchen & Pub (the logo lockup artwork still reads "Pan Asian Kitchen | Bar"; the wordmark-only files are unaffected).
