# Konso brand kit

Open `konso-brand-kit.html` (or the PDF). Folders: `logo/svg` (vector, use first), `logo/png` (6000 px), `logo/foil` (foil texture art), `fonts/` (Prata + Montserrat, OFL), `downloads/` (zips), `konso-tokens.css`, `brand-tokens.json`.

Colours: bottle green #051C0A, gold #D89D3C (foil gradient #EBB85B to #D19333), cream #F2E8D2.
Restaurant room palette (section 06): bottle, deep green, chocolate, brick, brass, cognac, burgundy, Goa blue and navy, bougainvillea, cream, ink.
Fonts: wordmark is artwork (never retype); Prata for headings; Montserrat for descriptor, labels, body.
Tagline: Pan Asian Kitchen & Pub. The lockup descriptor is redrawn (Montserrat SemiBold outlines, 2026-11-16); rebuild with python3 kit/tagline.py && python3 kit/build.py from Dream/Konso.
